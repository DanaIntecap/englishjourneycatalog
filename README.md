English Journey Master Catalog
Static catalog ready for GitHub Pages or Azure Static Web Apps. Upload the files in this folder to the repository root; no build step is required.

Files

style.css — responsive English Journey visual standard
app.js — JSON loading, filters and accessible resource cards
